# YouTube Fullscreen Zoom Controller

유튜브 전체화면에서 영상 배율을 조정하는 크롬 확장프로그램입니다.

## 기능

- 유튜브 재생창 우하단 컨트롤 바에 배율 버튼 추가
- 전체화면 상태에서 영상 축소/확대 비율 조정
- 버튼 클릭 시 `80% → 90% → 100% → 110% → 120%` 순환
- 설정값 자동 저장

## 설치 방법

1. 크롬에서 `chrome://extensions` 를 엽니다.
2. 오른쪽 위에서 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 폴더 `C:\Users\wns54\Documents\New project 3` 를 선택합니다.

## 동작 방식

- 유튜브 플레이어의 `.ytp-right-controls` 영역에 배율 버튼을 삽입합니다.
- 유튜브 페이지에서 전체화면 비디오 요소에 `transform: scale(...)`을 적용합니다.
- `100%`는 원래 크기이며, `80%`처럼 낮추면 화면 안에서 영상이 작아집니다.
- `120%`처럼 높이면 영상이 더 확대됩니다.
