# Chrome Web Store Listing Draft

## Name

YouTube Zoom Controller

## Short Description

Resize and reposition YouTube videos with on-player controls and keyboard shortcuts.

## Detailed Description

YouTube Zoom Controller adds simple zoom and position controls directly to the YouTube player.

Features:

- Add an `xx%` zoom button to the player controls
- Resize videos in both normal and fullscreen modes
- Move the visible video area with keyboard shortcuts
- Reset zoom and position instantly
- Save your preferred zoom and position automatically

Shortcuts:

- `Shift + Arrow Keys`: Move video position
- `Shift + +`: Increase zoom
- `Shift + -`: Decrease zoom
- `Shift + Backspace`: Reset zoom to `100%`
- `Shift + Delete`: Reset video position

Notes:

- This extension is designed for YouTube watch pages.
- Changes to YouTube's player UI may affect button placement or behavior over time.
- The extension stores zoom and position settings locally using Chrome storage.
